### 完整说明（4000 字符内）

```
电池大师 — 专业安卓电池充放电监测工具

【核心功能】
• 12 项充放电指标全量实时遥测：健康度、剩余电量、当前容量、设计容量、电量百分比、
  充放电状态、温度、健康状况、电压、循环计数、瞬时电流、完全充满容量
• 完全充满判定：100% 且浮充电流 ≤25 mA 自动锁定真实充满容量，跨会话保存
• 遥测分析：1Hz 三通道实时曲线（电压/电流/温度）、充放电会话统计、CSV 导出
• 健康档案：库仑计回归与单点估算双通道实测健康度，诚实标注数据来源
• 硬件实验室：四场景一键模拟（充满校准/极速闪充/高负载放电/过热警报）+ 六滑杆调参
• 硬件信息：SoC 五字段档案、PMIC、快充协议、电芯结构多级探测

【数据真实承诺】
• 每项指标显式标注数据来源（sysfs 实测 / 库仑计 / PowerProfile / 降级估算）
• 测不到就显示"无法测算"，不虚构数值
• 全部数据本地计算存储，不联网、不上传、无第三方 SDK

【零权限】
不申请任何运行时或危险权限，安装即可使用全部功能。
```

## 6. Beta / RC 发布轨道建议

1. **当前版本** v2.0.0-beta.1 → 上传至 **内部测试轨道**（Internal testing）；
2. 邀请 5~20 名内部测试者覆盖 docs/DEVICE_MATRIX.md 的 8 类设备；
3. 连续两个 beta 无 P0/P1 缺陷 → 升级 **封闭测试轨道**（Closed testing，≥20 人满足新账号要求）；
4. 封闭测试 ≥14 天且满足 Play 新个人开发者账号 20 测试者政策 → 申请新权限/转正式；
5. 正式版（去 -beta/-rc 后缀）→ 生产轨道（Production），并保留 staged rollout 10% 起步。
