# 电池大师 用户手册

> 适用版本：v2.0.0-beta.1 · 平台要求：Android 8.0 (API 26) 及以上 · 权限需求：无（零权限）

## 1. 认识电池大师

电池大师是一款**只读的电池充放电监测工具**：它像一台贴在手机上的"电池体检仪"，实时展示 12 项充放电指标、回溯历史曲线、统计充放电会话，并诚实标注每项数据来源。它**不能**修复电池、**不能**加速充电、**不联网**、**不申请任何权限**。

## 2. 四大功能页

| 页签 | 功能 | 典型用法 |
| --- | --- | --- |
| 状态总览 | 12 项指标仪表盘：电量、电压、电流、温度、健康度、循环计数等；底部"关于"卡 | 日常随手看一眼；查看应用版本与隐私声明 |
| 遥测分析 | 实时曲线（电压/电流/温度）、采集链路状态、充放电会话统计、CSV 导出 | 观察充电全程电流变化；导出数据做长期分析 |
| 健康档案 | 实测健康度（库仑计回归 / 单点估算双通道）、充满判定与锁定 | 鉴别二手电池健康状态；校准设计容量 |
| 硬件实验室 | 一键场景模拟（4 场景）+ 6 组滑杆调参 | 演示/教学/截图；**不会改真实电池** |

## 3. 快速上手

### 3.1 看懂状态总览

- **电量百分比**：当前电量（0~100%）。
- **电压 (mV)** / **电流 (mA)**：电流为正 = 充电，为负 = 放电；显示 "—" 表示该机型系统未提供（不虚构 0）。
- **温度 (°C)**：电池电芯温度，正常使用 25~40°C，快充可到 43°C 左右。
- **健康度 (%)**：实测当前容量 ÷ 设计容量；数据来源标注见 3.2。
- **循环计数**：显示 "—" 或估算值取决于电量计是否上报。

### 3.2 数据来源标注是什么意思

每项指标都标注了来源，诚实度从高到低：

| 标注 | 含义 |
| --- | --- |
| sysfs 实测 | 直接读取电量计硬件节点，最准确 |
| 库仑计 / 回归 | 由电流积分回归得出，充放电越久越准 |
| PowerProfile / 工程档案 | 系统功率档案或厂商档案推算 |
| 降级估算 | 系统未提供，按合理区间估算（明确标注非实测） |

**测不到的指标显示 "—（无法测算）"，应用绝不虚构数值。**

### 3.3 充满判定

把电池充到 100% 且浮充电流 ≤ 25 mA 时，应用会自动**锁定真实充满容量**并在健康档案保存（跨会话保留）。可手动清除校准记录。

### 3.4 遥测分析页

- **曲线**：1Hz 实时采样（电压/电流/温度三组），最多保留 120 点；数据本地 JSONL 持久化，**重启 App 自动接续**上次曲线。
- **充放电会话**：一次连续的充电或放电过程自动记为一个会话（起止电量、Δ电量、时长、均值电流），跨会话持久保存最近约 500 条。
- **导出 CSV**：点"导出曲线 CSV"或"导出会话 CSV"→ 系统分享面板 → 保存到网盘/发送给自己。
- **清空**：点"清空"并二次确认，删除全部本地历史（已导出的 CSV 文件不受影响）。

### 3.5 硬件实验室

1. 点"进入模拟"→ 界面切换为模拟数据（顶部提示"模拟数据生效中 · 真实遥测已冻结"）；
2. 一键场景：充满校准 / 极速闪充 / 高负载放电 / 过热警报；
3. 6 组滑杆独立调参（电量/电流/电压/温度/循环计数/设计容量）；
4. 点"恢复真实硬件遥测"退出，无缝回到真实数据。

> 模拟只改屏幕显示，不影响真实电池与系统设置，安全可玩。

## 4. 常见问题 FAQ

**Q1：健康度显示"无法测算"是我的电池坏了吗？**
A：不是。部分机型的电量计节点（如高通 bms、三星 maxfg、联发科 dc 平台）系统未开放读取，应用坚持不虚构数值。可继续充电放电，应用会用库仑计回归估算健康度（来源标注会变为估算通道）。

**Q2：电流显示 "—"？**
A：该机型 `BatteryManager.CURRENT_NOW` 未提供或返回异常值。应用显示 "—" 而非错误的 0 mA，这是诚实口径。

**Q3：充满判定一直不触发？**
A：需要同时满足"100% + 浮充电流 ≤ 25 mA"。部分快充机型到 100% 后电流仍偏大，建议保持插电 10~30 分钟观察；电流不可读机型（显示 "—"）无法判定，属预期。

**Q4：杀掉 App 再打开，曲线还在吗？**
A：在。遥测样本与充放电会话都会本地持久化（JSONL），重启自动接续；最多保留约 3000 条样本 / 500 条会话，超出滚动淘汰最旧的。

**Q5：应用会偷跑流量或耗电吗？**
A：不会。应用未申请网络权限（技术上无法联网），退后台后 1Hz 轮询自动暂停，仅保留系统广播被动监听。

**Q6：崩溃了怎么反馈？**
A：崩溃堆栈会自动记录在本地（最近 10 份）。到"状态总览 → 关于卡 → 导出崩溃日志"，通过分享面板把文件发给开发者即可。

**Q7：为什么模拟数据在 15 秒后消失？**
A：一键场景模拟（如"充满校准"）默认保持 15 秒，期间有倒计时提示，之后自动恢复真实硬件遥测——避免长期误用假数据。

**Q8：换手机/清数据后历史还在吗？**
A：应用数据未纳入云备份（已显式排除），卸载即清空。换机请先在旧设备导出 CSV。

## 5. 数据与隐私

- **零权限**：不申请任何运行时/危险权限；
- **零上传**：全部数据仅存本机私有目录，无网络传输能力；
- **零追踪**：无第三方统计/广告/崩溃 SDK；
- 完整政策见仓库 `PRIVACY.md`。
